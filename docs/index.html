KEEP IN MIND

Better examples beat a prettier percentage.

Clean

One flat target facing the sensor, with a clear path. Collect examples at several distances, not only 30 cm.

Clutter

Several surfaces in the sensing area. Change the objects and arrangement between recording runs.

Weak target return

An angled or poorly reflecting target. Background detections and missed echoes may occur; distance alone doesn’t measure signal strength.

The earlier Colab experiment classified 88 of 90 sessions correctly (97.8%). That was a fixed-setup experiment, not a promise of live accuracy. The current scores above are calculated from the current model’s test predictions.

Original feature ranges are context, not classification thresholds. Retraining can improve or reduce measured accuracy; no score is guaranteed.
